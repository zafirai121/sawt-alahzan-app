# حِكَم أمير المؤمنين الإمام علي عليه السلام — فيديو قصير سينمائي

فيديو عمودي (9:16) جاهز للنشر على TikTok وInstagram Reels وYouTube Shorts، مُنتَج بالكامل برمجيًا
وبأدوات مفتوحة تعمل دون اتصال (لا مفاتيح API، ولا صور أو موسيقى خارجية تحتاج إلى ترخيص).

| المخرَج | الوصف |
|---|---|
| `output/final_video.mp4` | الفيديو النهائي: ‎1080×1920، ‏30 FPS، ‏H.264 High (BT.709) + AAC ‏48 kHz، ‏33 ثانية، ‎-14 LUFS |
| `output/voiceover.wav` / `voiceover.mp3` | التعليق الصوتي المعالَج مستقلًا (WAV ‏24-bit ‏48 kHz، وMP3 ‏192 kbps) |

| `output/preview_contact_sheet.jpg` | لقطات معاينة من الفيديو |

## المحتوى والمشاهد

النص المنطوق كما ورد حرفيًا:
«مِنْ أَقْوَالِ أَمِيرِ الْمُؤْمِنِينَ، الْإِمَامِ عَلِيٍّ عَلَيْهِ السَّلَامُ... ضَرُورَاتُ الْأَحْوَالِ تُذِلُّ رِقَابَ الرِّجَالِ.
وَقَالَ أَيْضًا عَلَيْهِ السَّلَامُ... أَصْدَقُ الْمَقَالِ مَا نَطَقَ بِهِ لِسَانُ الْحَالِ».

1. **رواق الأقواس**: سواد يتسلل إليه ضوء ذهبي، ممر من الأقواس المدببة بنقوش نجمية ثمانية، دفع بطيء للكاميرا وذرات غبار مضاءة.
2. **الرمال والريح**: كثبان داكنة تحت سماء ثقيلة، رمال تقتلعها الريح من القمم، وضوء يشق الأفق ويتسع تدريجيًا.
3. **الإيوان**: قوس معماري مهيب بحجر أخضر داكن ونقوش ذهبية، ونافذة شمسية مشبّكة تتدفق منها أشعة ذهبية.
4. **الخاتمة**: خلفية سوداء، زخرفة خاتم ذهبية رفيعة، وذرات ذهبية تتلاشى مع عبارة «حِكَمٌ تلامسُ القلوبَ وتوقظُ العقولَ».

لا توجد أي وجوه أو شخصيات أو تجسيد؛ كل العناصر عمارة وطبيعة وضوء وجزيئات مولَّدة إجرائيًا.
الانتقالات: ذوبان عبر وهج دافئ، ثم ذوبان يقوده الضوء (تظهر المناطق المضيئة أولًا)، ثم انحدار نحو السواد.

## الصوت

- **التعليق**: صوت Piper العربي «kareem» (‏ar_JO، ذكوري) عبر sherpa-onnx دون اتصال. تُسجَّل كل عبارة عدة مرات
  (لأن التوليد عشوائي)، ويُفرَّغ كل تسجيل بـ Whisper large-v3-turbo، ويُختار التسجيل الذي يُفهم نصه كاملًا منفردًا
  **وفي سياق العبارة السابقة**. ثم: تعميق الطبقة بنحو نصف درجة صوتية مع الحفاظ على الصيغ (formants)، معادلة لدفء الصوت،
  ضغط خفيف، وصدى قاعة خفيف جدًا.
- **الموسيقى**: مؤلَّفة ومركَّبة داخل المشروع (وسائد وترية دافئة على مقام قريب من النهاوند/الحجاز، نغمة أرضية، لمعان
  خفيف)، بلا كلمات ولا غناء ولا مقاطع مقتبسة.
- **المؤثرات**: هواء ورياح (أعلى في مشهد الصحراء)، ارتفاع تدريجي قبل الانتقالات، نفخة هواء عند كل انتقال،
  رنين عميق ناعم، وكلها مركَّبة برمجيًا.
- **المزج**: الموسيقى والمؤثرات تنخفض ‎-6.5 dB تحت الإلقاء و‎-11 dB أثناء الحِكَم، وتلاشٍ تدريجي في النهاية،
  ثم تطبيع إلى ‎-14 LUFS مع ذروة ‎-1.5 dBTP.

## الكابشن

- خط **Tajawal** (Bold/Medium) بتشكيل كامل للحِكَم، مع تشكيل الحروف عبر HarfBuzz/Raqm (حروف متصلة، اتجاه من اليمين لليسار).
- عاجي مع كلمات مفتاحية بتدرّج ذهبي، هالة ظل ناعمة للقراءة فوق أي خلفية.
- كل سطر يظهر مع بداية نطق كلماته (قبلها بنحو 0.1 ث)، والكلمات تتكشف من اليمين لليسار، ولا يُعرض أكثر من سطرين.
- منطقة النص بعرض 800 بكسل في المنتصف، بعيدًا عن أزرار التطبيقات الجانبية وشريط الوصف السفلي.
- عبارة الخاتمة نص على الشاشة فقط وليست منطوقة، لذلك لا تظهر في ملف SRT.

## إعادة الإنتاج

```bash
pip install -r requirements.txt          # و ffmpeg (مع libx264 وrubberband)
./setup_models.sh --with-asr             # يحمّل الصوت (~80MB) ونموذج التحقق Whisper (~560MB) من GitHub
python3 make.py                          # بناء كامل (~15 دقيقة على 4 أنوية)
python3 make.py --skip-tts               # إعادة البناء بالتسجيلات الحالية
python3 make.py --no-music               # نسخة بديلة: أجواء ومؤثرات فقط دون موسيقى
```

المراحل (`src/`): ‏`tts.py` (التعليق والخط الزمني) ← `audio.py` (الموسيقى والمؤثرات والمزج) ← `render.py`
(الصورة، بالتوازي، مع FFmpeg) ← `subtitles.py` ← دمج ← `verify.py` (الفحوص). النصوص والتوقيتات والألوان في `src/config.py`.
لتغيير الحكمة يكفي تعديل `VOICE_CHUNKS` و`CAPTIONS` ثم `python3 make.py`؛ فالمشاهد والانتقالات تُشتق من توقيت الصوت تلقائيًا.

## ملاحظات وتراخيص

- الخطوط Tajawal وCairo وAmiri برخصة SIL OFL (الملفات في `assets/fonts`).
- نموذج الصوت kareem من مجموعة أصوات Piper؛ بطاقة النموذج تحيل إلى مستودع البيانات
  `AliMokhammad/arabicttstrain` لمعرفة ترخيص البيانات، ولم يكن الوصول إليه متاحًا من بيئة البناء. يُستحسن مراجعته قبل
  أي استخدام تجاري.
- الصوت المولَّد آليًا أقل طبيعية من قارئ بشري. لاستبداله بصوت تجاري أعلى جودة (مثل Azure Neural أو ElevenLabs) يلزم
  مفتاح API من المزوّد؛ ويمكن أيضًا تسجيل قارئ بشري ووضع الملف مكان `output/voiceover.wav` مع ضبط التوقيتات في `build/timeline.json`.
