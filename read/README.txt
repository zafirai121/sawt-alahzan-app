The texts of the "اقرأ" part (tools/read/build.mjs builds them; read-sources.yml runs it):

- t/: du'as, ziyarat and al-Sahifa al-Sajjadiyya, from Arabic Wikisource
  (https://ar.wikisource.org), licensed CC BY-SA 4.0
  (https://creativecommons.org/licenses/by-sa/4.0/). Wiki markup removed and
  Persian letters typed by mistake (ی، ک) made Arabic; each file names its page.
- t/ (the others): du'as, ziyarat, the fifteen munajat and the ta'qibat from
  Shaykh Abbas al-Qummi's Mafatih al-Jinan (in the public domain), its proofread
  pages on Persian Wikisource (https://fa.wikisource.org), licensed CC BY-SA 4.0.
  The Arabic as it is; the author's Persian notes left out, but for what the
  reader needs (how many times, what to do), written in Arabic; Persian letters
  (ی، ک) made Arabic. Each file names its page.
- q/: the Quran, Tanzil Quran Text (Uthmani, Version 1.1), Copyright (C)
  2007-2026 Tanzil Project, licensed CC BY 3.0, verbatim; each file carries
  Tanzil's notice in full. https://tanzil.net
